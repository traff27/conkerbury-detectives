# Conkerbury Detectives Club website (static)

Companion site and sales landing page for "The Conkerbury Detectives: The Case of the Missing Conker Champion" by Inspector Cuthbert Conkerworth.
Hosted on GitHub Pages (repo traff27/conkerbury-detectives) at https://conkerburydetectives.co.uk/ (site/CNAME).

Generated by `python3 site_src/build_site.py` from the solver-checked case files. Don't hand-edit the HTML, `data/`, sitemap.xml, robots.txt or llms.txt. Edit build_site.py and rebuild. (app.js, style.css and img/ are edited directly.)

## When the book goes live on Amazon
1. In site_src/build_site.py set `BOOK_URL = "https://www.amazon.co.uk/dp/..."` (one constant) and rebuild.
   Every "Get the book" button becomes a real link, the "coming soon" wording changes, and the schema.org Book data gains offers/sameAs.
2. Quick fix without a rebuild: paste the URL into `data/book.js` (`window.BOOK_URL = "..."`). The buttons switch at runtime, but the wording and schema stay "coming soon" until you rebuild.
3. Update LASTMOD in build_site.py and re-upload the changed files.

## Preview
Double-click index.html (works from file://), or `cd site && python3 -m http.server 8765` and open http://localhost:8765

## Privacy
No cookies, analytics, storage or third-party requests. Fonts, images and scripts are all self-hosted. The newsletter form is disabled (CSP form-action 'none'). Contact: hello@conkerburydetectives.co.uk.

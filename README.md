# Conkerbury Detectives Club website (static, NOT deployed)

Generated by `python3 site_src/build_site.py` from the solver-checked case files. Don't hand-edit `data/`.

Preview locally: just double-click index.html (tested 1 Nov 2026: the answer checker and bonus case work from file:// in Chrome/Edge, all 30 cases pass). Or serve it:

    cd site && python3 -m http.server 8765   # then open http://localhost:8765

GitHub Pages later (only with Mark's OK): push the contents of this folder (including CNAME) to a repo and enable Pages.
Domain: conkerburydetectives.co.uk (registered by Mark, 1 Nov 2026). Every page has a canonical link to it. Nothing is deployed and no DNS is set up.
Hosting: GitHub Pages (not set up yet). site/CNAME holds conkerburydetectives.co.uk for the custom domain. Contact email on the privacy and parents pages: hello@conkerburydetectives.co.uk.
Privacy: no cookies, analytics, storage or third-party requests. The newsletter form is disabled and cannot submit (CSP form-action 'none').
